## Build on infrastructure anyone can verify.

**[KXCO](https://kxco.ai)** — the trust stack for the human–AI economy, from
the Knightsbridge Group. People, institutions, and AI agents sign, verify,
settle, and issue identities using open-source post-quantum cryptography and
a live settlement network.

**All KXCO code is published under the [Knightsbridge AIQ organization →](https://github.com/KnightsbridgeAIQ)**

## Start in 60 seconds

```sh
npm install kxco-pq        # the full post-quantum stack, one install
npx kxco-pq keygen         # generate a keypair — for a person or an AI agent
```

| | |
|---|---|
| [kxco-post-quantum](https://github.com/KnightsbridgeAIQ/kxco-post-quantum) | ML-DSA-87 and ML-DSA-65, ML-KEM-1024 and ML-KEM-768 primitives (NIST FIPS 204 / 203) |
| [kxco-verify](https://github.com/KnightsbridgeAIQ/kxco-verify) | Verifies any KXCO signature — browser or server, no KXCO server required |
| [kxco-pq-webhook](https://github.com/KnightsbridgeAIQ/kxco-pq-webhook) | Dual-signed webhooks for Express, Fastify, Hono, Workers, Vercel |

NIST-standardized and built on independently audited primitives.
